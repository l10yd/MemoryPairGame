# 🎴 MEMORY PAIR — «Найди пару»

Классическая игра на память «найди пару» на **React + Vite**: переворачивай клетки,
запоминай, где прячется парная (или тройная!) картинка, и очищай поле за минимум шагов.
Старый Replit-прототип переехал на Vercel — теперь без всяких плашек «Run on Replit».

> 🎮 **Играть онлайн:** <https://memory-pair-game-snowy.vercel.app/>
> Игра входит в хаб браузерных игр **GOSU**.

## Что внутри

- **Пары или Тройки** — открывай по две или по три клетки за ход.
- **Поле от 3×3 до 9×9** — чётные размеры для пар, кратные трём — для троек.
- **Сложность 2–16 уникальных картинок** на поле: от разминки до жёсткой стены.
- **4 режима**: Обычный (считается время победы), Выживание (жизни: промах — минус,
  совпадение — плюс), Гонка на время (таймер тикает назад, совпал — добавил секунды)
  и Выживание на время (оба счётчика сразу).
- **14 эмодзи-тем по 16 картинок**: фрукты, машины, природа, животные, эмодзи, спорт,
  еда, погода, сладости, одежда, страшное, гороскоп, музыка и «18+».
- **Рекорды** отдельно по каждому типу игры, полю, сложности и режиму — в localStorage.
- **Русский и English** интерфейс, тёмная тема, звук, случайные реплики
  при успехе/промахе, адаптивный размер клеток под окно браузера.
- Всё состояние игры (поле, счётчики, таймер, настройки) живёт в localStorage:
  закрыл вкладку — вернулся и продолжил с того же места.

## Правила

Все клетки закрыты. Открываешь две (или три): совпали — остаются открытыми,
не совпали — закрываются обратно после секундной паузы. Цель — открыть всё поле.
Очки — это шаги: победа фиксируется за минимум открываний, а время и жизни
учитываются по режиму.

## Технологии

| Слой | Что |
|---|---|
| UI | React 18 (JSX), plain CSS |
| Логика | чистые утилиты в `src/GameUtils.jsx` / `src/RecordUtils.jsx` |
| Сборка | Vite 4 |
| Деплой | Vercel (продакшн-билд с GitHub) |

## Структура

| Файл | Назначение |
|---|---|
| `index.html` | точка входа Vite |
| `src/index.jsx` | бутстрап React |
| `src/App.jsx` | вся игра: поле, выбор клеток, таймер, настройки, темы |
| `src/GameUtils.jsx` | перемешивание картинок, генерация сетки, таймер |
| `src/Pictures.jsx` | 14 тем по 16 эмодзи |
| `src/Languages.jsx` | тексты интерфейса (ru / en) |
| `src/Messages.jsx` | случайные реплики при успехе и промахе |
| `src/RecordUtils.jsx` | рекорды в localStorage |
| `src/Difficulties.jsx` | историческая заглушка уровней (заменена слайдером 2–16) |

## Запуск

```bat
npm install
npm run dev      # http://localhost:5173
npm run build    # статика в dist/
```
